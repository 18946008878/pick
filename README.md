# 破天一剑 - 文字版武侠RPG手机游戏

## 游戏简介

这是一款基于经典破天一剑的文字版武侠RPG手机游戏。游戏以星宿宇宙为背景，玩家需要扮演武者，寻找三件亘古圣物，击败逆天之神，拯救宇宙。

## 游戏特色

- **丰富的角色系统**: 四个不同职业的角色，各具特色
- **深度剧情**: 基于原作世界观的全新剧情线
- **战略战斗**: 回合制战斗系统，需要合理运用武功和道具
- **成长系统**: 完整的等级、技能、装备升级体系
- **存档系统**: 支持本地存档，随时保存游戏进度

## 如何运行

### 方式一：直接运行
1. 下载所有文件到同一目录
2. 用手机浏览器打开 `index.html` 文件
3. 开始游戏

### 方式二：本地服务器
1. 安装 Python 或 Node.js
2. 在游戏目录运行本地服务器：
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Python 2
   python -m SimpleHTTPServer 8000
   
   # Node.js (需要先安装 http-server)
   npx http-server
   ```
3. 在手机浏览器访问 `http://localhost:8000`

## 游戏角色

### 一剑
- **职业定位**: 近战输出
- **特色**: 掌握乾光之力，攻击力最强
- **适合玩家**: 喜欢正面硬刚的玩家

### 秀雅
- **职业定位**: 远程射手
- **特色**: 善用火系弓箭，敏捷型角色
- **适合玩家**: 喜欢远程风筝的玩家

### 指路
- **职业定位**: 灵活刺客
- **特色**: 突进控制兼备，操作性强
- **适合玩家**: 喜欢技巧操作的玩家

### 拇指
- **职业定位**: 治疗辅助
- **特色**: 善用陷阱和天雷，团队支援
- **适合玩家**: 喜欢策略布局的玩家

## 游戏系统

### 战斗系统
- 回合制战斗，玩家和敌人轮流行动
- 可以选择攻击、武功、道具、逃跑
- 武功消耗内力但伤害更高
- 合理使用道具是获胜关键

### 成长系统
- 击败敌人获得经验值升级
- 升级提升四维属性和血量内力上限
- 学习新武功增强战斗能力
- 收集装备提升战斗力

### 物品系统
- **破天铜牌/银牌**: 游戏货币，用于购买物品
- **活血丹**: 恢复生命值
- **回神丹**: 恢复内力值
- **经验丹**: 直接获得经验值
- **装备**: 提升攻击力和防御力

## 游戏操作

### 基础操作
- **选择角色**: 点击角色卡片选择职业
- **剧情选择**: 点击选项按钮推进剧情
- **查看状态**: 点击"状态"按钮查看角色信息
- **管理背包**: 点击"背包"按钮查看和使用物品
- **武功查看**: 点击"武功"按钮查看已学武功
- **保存游戏**: 点击"存档"按钮保存进度

### 战斗操作
- **攻击**: 进行普通攻击
- **武功**: 使用技能攻击（消耗内力）
- **道具**: 使用背包中的回复道具
- **逃跑**: 尝试逃离战斗

## 游戏世界观

### 背景设定
创世之初，太极八卦封印了创世之神和逆天之神互通的神界之门。如今紫微星转暗，创世之神消陨，逆天之神势力膨胀，整个宇宙陷入黑暗。

### 三件亘古圣物
- **破天剑**: 藏在午灵星的护法手中
- **破天牌**: 在申灵星的神庙里
- **破天秘笈**: 在天极星的仙人洞府

### 十二星宿世界
游戏世界由十二个星球组成，每个星球都有独特的环境和护法BOSS。

## 开发技术

- **前端**: HTML5 + CSS3 + JavaScript
- **响应式设计**: 适配手机和桌面端
- **本地存储**: 使用 localStorage 保存游戏进度
- **无依赖**: 纯原生代码，无需额外框架
