# 破天一剑 - 文字版武侠RPG手机游戏

## 游戏简介

这是一款基于经典破天一剑的文字版武侠RPG手机游戏。游戏以星宿宇宙为背景，玩家需要扮演武者，寻找三件亘古圣物，击败逆天之神，拯救宇宙。

## 🎮 游戏特色

- **丰富的角色系统**: 四个不同职业的角色，各具特色
- **深度剧情**: 基于原作世界观的全新剧情线
- **战略战斗**: 回合制战斗系统，需要合理运用武功和道具
- **成长系统**: 完整的等级、技能、装备升级体系
- **存档系统**: 支持本地存档，随时保存游戏进度
- **💫 个性化设置**: 丰富的自定义选项，适应不同玩家需求
- **♿ 无障碍功能**: 支持视障、听障等特殊需求玩家

## 如何运行

### 方式一：直接运行
1. 下载所有文件到同一目录
2. 用手机浏览器打开 `index.html` 文件
3. 开始游戏

### 方式二：本地服务器
1. 安装 Python 或 Node.js
2. 在游戏目录运行本地服务器：
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Python 2
   python -m SimpleHTTPServer 8000
   
   # Node.js (需要先安装 http-server)
   npx http-server
   
   # 或者使用提供的Python启动脚本
   python start_game.py
   ```
3. 在手机浏览器访问 `http://localhost:8000`

## 🎯 游戏角色

### 一剑
- **职业定位**: 近战输出
- **特色**: 掌握乾光之力，攻击力最强
- **适合玩家**: 喜欢正面硬刚的玩家

### 秀雅
- **职业定位**: 远程射手
- **特色**: 善用火系弓箭，敏捷型角色
- **适合玩家**: 喜欢远程风筝的玩家

### 指路
- **职业定位**: 灵活刺客
- **特色**: 突进控制兼备，操作性强
- **适合玩家**: 喜欢技巧操作的玩家

### 拇指
- **职业定位**: 治疗辅助
- **特色**: 善用陷阱和天雷，团队支援
- **适合玩家**: 喜欢策略布局的玩家

## ⚙️ 设置系统详解

### 🎨 显示设置
- **界面主题**: 4种精美主题可选
  - 经典武侠：传统蓝金配色
  - 暗夜江湖：深色护眼模式
  - 明亮仙境：清新明亮风格
  - 紫气东来：神秘紫色主题
- **文字大小**: 12-20px可调节，适应不同视力需求
- **动画效果**: 可关闭所有动画，提升性能或减少干扰
- **自动保存**: 每分钟自动备份进度

### 🎮 游戏设置
- **游戏难度**: 
  - 简单：经验+50%，受到伤害-25%
  - 普通：标准游戏体验
  - 困难：经验-25%，受到伤害+50%
  - 专家：经验-50%，受到伤害+100%
- **文字速度**: 调节剧情文字显示速度
- **操作确认**: 重要操作是否需要二次确认
- **战斗自动**: 启用后战斗自动选择最优策略

### 🔊 音效设置
- **主音量**: 控制整体音量大小
- **背景音乐**: 单独调节BGM音量
- **音效**: 单独调节音效音量
- **震动反馈**: 手机震动反馈开关

### ♿ 辅助功能
- **高对比度模式**: 提升视觉对比度，适合视力不佳用户
- **大按钮模式**: 放大所有按钮和文字，便于操作
- **屏幕阅读器支持**: 优化焦点管理，支持语音阅读
- **按钮延迟**: 为运动障碍用户设置按钮激活延迟

### 💾 数据管理
- **导出存档**: 将游戏进度和设置导出为JSON文件
- **导入存档**: 从本地文件恢复游戏进度
- **重置设置**: 将所有设置恢复为默认值
- **清除数据**: 完全清除所有本地数据

## 🎯 游戏玩法

### 角色成长
- **等级系统**: 通过战斗和任务获得经验值提升等级
- **属性分配**: 力量、敏捷、智力、体质四大属性
- **武功修炼**: 学习不同元素的武功招式
- **装备收集**: 获得各种武器、防具和饰品

### 战斗系统
- **回合制战斗**: 策略性强，需要合理运用技能
- **属性相克**: 火、冰、雷、毒等属性相互克制
- **武功连招**: 不同武功组合产生特殊效果
- **道具使用**: 恢复类、增益类道具辅助战斗

### 剧情探索
- **分支剧情**: 选择影响故事发展方向
- **隐藏任务**: 探索发现秘密剧情线
- **收集要素**: 寻找三件亘古圣物
- **多重结局**: 根据玩家选择有不同结局

## 🌟 世界观设定

### 宇宙结构
- **紫微星**: 太初宇宙的中心
- **三极星**: 天极星、人极星、地极星
- **四象星**: 东方青龙、西方白虎、南方朱雀、北方玄武
- **十二圣灵星**: 对应十二星座的神秘星球

### 故事背景
创世之初，太极八卦封印了创世之神和逆天之神互通的神界之门。如今紫微星转暗，创世之神消陨，逆天之神势力膨胀。四天王、四方神、十二圣灵护法迷失本性，成为逆天之神的傀儡。

玩家作为人极星的武者，必须寻找三件亘古圣物：
- **破天剑**: 传说中的神器
- **破天牌**: 封印的钥匙  
- **破天秘笈**: 终极武功秘籍

最终目标是击败逆天之神，让太极八卦盘正转，恢复宇宙和平。
